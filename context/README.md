# راهنمای یادداشت‌های فرانت‌اند

`CONTEXT_*.md`ها یادداشت‌های زمان انجام کار هستند و لزوماً وضعیت امروز کد یا قرارداد API را نشان نمی‌دهند. فایل‌های `old/` پیشینهٔ کارهای قبلی‌اند. `CHANGELOG.txt` تاریخچهٔ تغییرات را نگه می‌دارد؛ [فهرست پیگیری مشترک](../../../ByeMoney/TASKS.md) محل ثبت موارد جامانده است.

برای کارهای مرتبط با کیف پول، شارژ و سفارش، [قرارداد اتصال](../../../ByeMoney/docs/integration/ByeMoney-Strapi-Integration.md) و [تصمیم‌های بای‌مانی](../../../ByeMoney/docs/architecture/ByeMoney-Decisions.md) مرجع‌اند. `CONTEXT_BYEMONEY_INTEGRATION.md` فقط راهنمای تاریخی فرانت‌اند است و اگر با این دو سند یا کد فعلی اختلاف داشت، به آن استناد نکنید.

`CONTEXT_PROJECT_OVERVIEW.md` و `CONTEXT_RULES.md` تصویر اولیهٔ پروژه‌اند و چند مسیر و تصمیم قدیمی دارند؛ آن‌ها را به‌عنوان دستورالعمل فعال برای تغییرات جدید به کار نبرید. برای جزئیات یک بخش رابط، یادداشت همان بخش و سپس پیاده‌سازی فعلی را بخوانید.
